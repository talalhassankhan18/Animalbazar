# 🐾 Animal Bazar

A modern Flutter-based mobile marketplace for pet lovers, designed to simplify the process of buying, selling, and discovering pets. Animal Bazar provides an intuitive and user-friendly platform where users can explore pet listings, connect with sellers, and manage pet-related transactions seamlessly.

## 📖 Overview

Animal Bazar is a mobile application developed using Flutter that connects pet buyers and sellers through a centralized digital platform. The application aims to make pet adoption and trading easier by providing a clean interface, categorized listings, and a smooth user experience.

Whether users are searching for a new companion or looking to sell pets responsibly, Animal Bazar offers a convenient marketplace accessible from anywhere.

## 🚀 Getting Started

### Prerequisites

Before running this project, make sure you have:

- Flutter SDK installed
- Dart SDK installed
- Android Studio or VS Code
- Android Emulator or Physical Device

Verify Flutter installation:

```bash
flutter doctor
```

---

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/talalhassankhan18/Animalbazar.git
```

### Navigate to Project Directory

```bash
cd Animalbazar
```

### Install Dependencies

```bash
flutter pub get
```

---

## ▶️ Running the Application

### Run on Android Emulator / Connected Device

```bash
flutter run
```

### Run in Debug Mode

```bash
flutter run --debug
```

### Build APK

```bash
flutter build apk
```

### Build Release APK

```bash
flutter build apk --release
```

### Build for iOS

```bash
flutter build ios
```
